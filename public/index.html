Orbit

Starscape Orbit

A developer-first kanban board built for teams working alongside AI agents. Track the motion of your project — and hand work to your coding agent through the Orbit MCP tools.

Getting started

  1. 01

    Create a board

    Use the Board menu → New board. Optionally point it at a coding project folder so Orbit can drop SKILL-ORBIT.md and AGENTS.md for your agent.

  2. 02

    Add cards & the AI Ready lane

    Capture work with New Card. Move cards into AI Ready to stage them for an agent to claim.

  3. 03

    Connect your coding agent

    Add the Orbit MCP server from Settings, then ask your agent to read AGENTS.md and claim the next ticket.
